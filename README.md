# Hawasly Code — Portfolio & CV

Currículum web interactivo con estética Apple Liquid Glass.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite 6** (build tool)
- **Tailwind CSS v4** (design system)
- **Lucide React** (icons)

## Quick Start

```bash
npm install
npm run dev
```

## Project Structure

```
src/
├── components/
│   ├── GlassCard.tsx          # Base glass container
│   ├── ModernButton.tsx       # Button with variants
│   ├── SectionContainer.tsx   # Section layout wrapper
│   └── index.ts               # Barrel exports
├── data/
│   └── cvData.ts              # All CV content
├── types/
│   └── cv.ts                  # TypeScript interfaces
├── App.tsx                    # Root component
├── main.tsx                   # Entry point
└── index.css                  # Tailwind + design tokens
```
